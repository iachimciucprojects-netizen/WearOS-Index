How to use WearOS Index

Open watch comparison

What is WearOS Index?

WearOS Index is a community directory covering watches from any manufacturer, including older Android Wear models. The comparison brings records from the directory into one table.

Compare watches

  1. Pick two watches and, optionally, a third. Models are grouped by manufacturer.
  2. Use Show differences only to hide rows where all the selected watches have the same known value.
  3. Use Copy comparison link to share the models and language you selected.

Read the results

Each model shows how many of the 18 criteria are documented and links to its source. Unknown means we do not have verified data. Battery capacity in mAh is not runtime, and manufacturers' battery-life figures use different test conditions.

Help improve the directory

Suggest a missing device · Report something you tested

For a test, include the exact model, Wear OS version, build number and what happened. Do not include serial numbers, account details or tokens.
