Открыть сравнение часов

Что такое WearOS Index?

WearOS Index — открытый каталог часов с Wear OS от разных производителей, включая старые модели на Android Wear. На сайте можно сравнить устройства из каталога в одной таблице.

Как сравнить часы

  1. Выбери две модели. При желании добавь третью. Список сгруппирован по производителям.
  2. Включи «Показать только различия», чтобы скрыть строки, где у всех выбранных часов одинаковые подтверждённые данные.
  3. Нажми «Скопировать ссылку», чтобы поделиться выбранными часами и языком.

Как читать таблицу

У каждой модели видно, по скольким из 18 критериев есть данные и откуда они взяты. «Не подтверждено» не означает, что функции нет. Ёмкость в мА·ч не равна времени работы. Автономность нельзя напрямую сравнивать, если производители измеряли её в разных условиях.

Как помочь проекту

Предложить недостающую модель · Поделиться результатом теста

В отчёте укажи точную модель, версию Wear OS, номер сборки и что получилось. Не публикуй серийные номера, данные аккаунта и токены.
