# Wear OS device directory

[Back to WearOS Index](../README.md) · [Suggest a missing device](https://github.com/iachimciucprojects-netizen/WearOS-Index/issues/new?template=device.yml) · [Share a device or app result](https://github.com/iachimciucprojects-netizen/WearOS-Index/issues/new?template=compatibility.yml)

This index covers Wear OS wearables from **any manufacturer and region**, and includes historical Android Wear devices. A device belongs here if a manufacturer, Google, or a reproducible device report identifies Wear OS or Android Wear for the exact variant. Similar names, Android phone pairing, and Android-based vendor software do not establish Wear OS support. Other form factors are welcome with the same evidence.

This is an initial directory of **54 model and variant entries from 17 brands**, not a complete list. A model link is documentation, not a test performed by this project. Software versions below are tied to the cited document; we do not assert the newest installed build. A blank compatibility record means no report yet.

## Rollouts, firmware and regional variants

- **Google Pixel Watch:** [support periods](https://support.google.com/product-documentation/answer/12799779?hl=en), [official factory images](https://developers.google.com/android/images-watch), [official full OTA packages](https://developers.google.com/android/ota-watch). Availability is model/build-specific. An image is not the full source code.
- **Samsung:** [official Wear OS setup](https://www.samsung.com/us/support/answer/ANS10003348/) and [an example of an update announcement](https://news.samsung.com/global/samsung-expands-availability-of-latest-wearable-experiences-to-more-users). Use the actual model code, region, carrier where relevant, and Bluetooth/LTE variant. [Galaxy Watch for Kids](https://news.samsung.com/us/how-to-use-new-samsung-galaxy-watch-experience-for-kids-unpacked2025/) is an experience on Galaxy Watch7 LTE, not a separate hardware entry.
- **Mobvoi:** [official upgrade history](https://www2.mobvoi.com/uk/pages/upgrade-history) and [TicWatch Pro 5 source/firmware notes](ticwatch-pro-5.md#updates-and-source-code). Kernel source, OTA packages and alternative ports are different artifacts.
- **Other brands:** [Google's manufacturer help directory](https://support.google.com/wearos/answer/10106605) is a starting point, not evidence that every model sold by a brand runs Wear OS. Keep regional siblings separate; source availability for one is not evidence of availability for another.
- **Not included:** Samsung's pre-Watch4 Tizen models, TAG Heuer Calibre E5, and hardware variants running a different OS. If a product has a low-power RTOS alongside Wear OS, record the mode when testing compatibility.
